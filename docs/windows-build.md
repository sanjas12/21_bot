# 21_bot для Windows

Распакуйте весь ZIP в отдельную доступную для записи папку, например
`C:\Apps\21_bot`. Нужна 64-битная Windows, Python устанавливать не нужно.
Оставьте рядом с `21_bot.exe` все библиотеки и папку `lib`.

1. Скопируйте `.env.example` в `.env` рядом с `21_bot.exe`.
2. В `.env` заполните `BOT_TOKEN` токеном своего бота.
3. Запустите `21_bot.exe`. Консоль должна оставаться открытой.
4. В Telegram отправьте боту `/start`.

База создаётся в `data/calendar.sqlite3` рядом с программой. CHANGELOG находится
в `docs/CHANGELOG.md`, настройки — в `.env`. Пути не зависят от рабочей папки
или ярлыка. При обновлении остановите приложение и сохраните `.env` и весь `data/`.
Готовый архив не содержит ваших настроек, токена и базы.

Для проверки приложения без токена, сети и запуска бота выполните в PowerShell:

```powershell
.\21_bot.exe --check
```

Не запускайте одновременно серверную и Windows-копию с одним BOT_TOKEN:
Telegram polling рассчитан на один работающий экземпляр этого бота.

## Сборка из исходников

Нужны 64-битные Windows и Python 3.11+, uv и Git Bash. Из корня проекта:

```bash
bash scripts/build.sh --prepare
```

Повторная сборка из готового окружения без загрузок:

```bash
bash scripts/build.sh
```

Установка зависимостей только из локального кэша uv:

```bash
bash scripts/build.sh --prepare-offline
```

Версия читается из `pyproject.toml`. Результат — `build/21_bot-VERSION-windows-x64/`
и `dist/21_bot-VERSION-windows-x64.zip`. Перед повторной сборкой удаляется только
каталог результата этой версии; другие версии и исходники сохраняются.
Перед упаковкой автоматически выполняется `21_bot.exe --check`.
Эти команды ничего не публикуют в GitHub и не обновляют сервер.
